SocialMedia AI Videos

An AI-assisted application for preparing, managing and publishing video content to authorized social media accounts. The application is developed and operated by eStockUp Venture.

About the Application

SocialMedia AI Videos helps users prepare video content using AI-assisted workflows and publish that content to social media platforms through accounts that the user has explicitly authorized.

Application Functionality

The current Google integration is focused on YouTube publishing workflows.

AI-Assisted Video Preparation

Users can prepare and organize video content using AI-assisted content creation workflows before publishing.

YouTube Account Connection

Users can connect an authorized YouTube account through Google's OAuth authorization process.

Video Publishing

Users can initiate video uploads and publishing workflows to their authorized YouTube account.

Google & YouTube Data Usage

Google authorization is requested only when required to provide the application's YouTube functionality.

Why Google Data Is Requested

Google/YouTube authorization allows the application to perform YouTube actions that the user explicitly initiates, such as connecting the user's YouTube account and publishing videos.

User Authorization

Users must explicitly authorize access through Google's OAuth consent process. The application does not request access to Google data unrelated to its enabled YouTube functionality.

Data Processing and Storage

Application processing is primarily performed on the user's local computer. Google user data is not sold or used for advertising purposes.

Limited Use of Google Data

Google user data is used only to provide the YouTube-related functionality requested and authorized by the user.

Privacy & Data Protection

We aim to minimize the collection and retention of user data. Please review our Privacy Policy for detailed information about data handling, Google API usage, security and user rights.
